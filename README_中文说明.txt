安川机器人焊接数字化监控平台 V5.3（后台数据库版）

本版新增：
- Flask 网站后台
- SQLite 数据库保存27条标准配方
- 报警记录持久化保存
- 页面顶部显示后台连接状态
- 保留手机/电脑自适应界面
- Render Python Web Service 部署配置

第一阶段：在电脑本地运行
1. 安装 Python 3.10 或更新版本。
2. 在本文件夹空白处按住 Shift 并右键，选择“在终端中打开”。
3. 执行：
   python -m venv .venv
4. Windows PowerShell 执行：
   .\.venv\Scripts\Activate.ps1
   如果提示执行策略限制，可改用 CMD 终端执行：
   .venv\Scripts\activate.bat
5. 安装依赖：
   python -m pip install -r requirements.txt
6. 启动网站：
   python server.py
7. 浏览器打开：
   http://127.0.0.1:5000

检查方法：
- 页面顶部应显示“网站后台：已连接”。
- 在焊缝配方页修改一项标准值，点击“保存人工修改”。
- 刷新网页，修改值应保留。
- 点击“模拟一条参数修改”，报警中心会新增记录；刷新后记录仍应保留。

重要：
- 本版只实现网站后端和数据库保存，仍未连接安川机器人控制器。
- 机器人状态、实时电压/电流和趋势图仍是演示数据。
- 当前数据库是本地 SQLite 文件 data/welding_monitor.db。部署到 Render 时，普通临时磁盘可能在重启/重新部署后丢数据；正式上线需配置持久化磁盘或外部数据库。
- 请不要把端口5000直接暴露到公网。
- 上线前仍需确认现场机器人通信协议、寄存器映射和每条焊缝设定值的读取方式。
